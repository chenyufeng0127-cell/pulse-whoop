隐私说明

本说明描述一个个人使用的助手，在使用者本人日后授权之后，打算如何处理此人自己的 WHOOP 数据。这不是 WHOOP 官方网站，与 WHOOP 没有附属、代理或背书关系。WHOOP 是其权利人的商标。

更新日期：2026年11月16日。这是准备阶段的说明。下面关于字段的描述，依据的是当日可以读到的 WHOOP OAuth 文档和 WHOOP API 文档。若 WHOOP 以后改变字段，以他们当时的文档为准。用途仍然限于个人的训练和恢复参考。

现在这个页面收集什么

不收集健康数据。你正在看的是放在公开仓库里的静态说明，当前处于准备阶段。打开本页不会连接 WHOOP，也没有测量、同步或登录功能。

  • 没有账号、表单或搜索框。
  • 不要求姓名、电子邮箱、WHOOP 密码、客户端密钥、授权码或令牌。
  • 不读取、不展示、不保存恢复、Strain、睡眠、心率变异性（HRV）、静息心率（RHR）或锻炼数据。
  • 不设置分析或广告 Cookie，不加载第三方脚本、字体、像素或统计服务。

因此，这份静态说明本身没有健康数据可以保留、出售或共享。浏览器向托管方发出的普通页面请求，见下文“托管”。

以后若你授权，打算处理哪些数据

只有在你本人之后于 WHOOP 的授权页同意，并且令牌交换在你自己的机密客户端完成时，助手才会处理你的 WHOOP 数据。令牌交换还没有在这些静态页面里实现。

数据 打算请求的权限 用途
恢复记录。WHOOP 文档写明其中包括恢复分数、心率变异性（HRV，RMSSD）和静息心率（RHR）。同一条恢复记录目前还可能带有血氧百分比和皮肤温度。 read:recovery 个人恢复参考。血氧和皮肤温度若随记录一起到来，也只作为同一份恢复情况的上下文。
生理周期。WHOOP 文档写明其中包括当天 Strain，以及该周期的平均心率。记录里目前还可能有能量消耗和最高心率。 read:cycles 了解自己当天的训练负荷。
睡眠。WHOOP 文档写明其中包括睡眠表现和各睡眠阶段的时长。记录里目前还可能有睡眠效率、一致性和呼吸频率。 read:sleep 个人恢复参考。
锻炼。WHOOP 文档写明其中包括活动 Strain 和平均心率。记录里目前还可能有运动类型、时长、距离、海拔和心率区间。 read:workout 个人训练参考。

这些接口的记录里可能含有 WHOOP 分配的数字标识，例如用户编号或某条记录的编号。助手不用这些标识建立公开的身份档案，也不会把它们放进本仓库。

不打算请求的数据

  • 不请求 read:profile。按 WHOOP 文档，该范围包含姓名和电子邮箱。
  • 不请求 read:body_measurement。按 WHOOP 文档，该范围包含身高、体重和最大心率。
  • 这些静态页面不请求 offline，也不实现刷新令牌。
  • 不向你索取 WHOOP 密码。客户端密钥只应留在你自己的机密客户端中，不能出现在浏览器、本仓库或普通聊天里。

用来做什么

用途是给你本人做训练和恢复方面的参考，例如结合恢复情况、当天 Strain、睡眠和锻炼，帮助你安排自己的活动强度。

这些内容不是诊断，不是治疗，也不是医学建议。它们不能用来判断、证明或排除任何健康状况，也不能代替有资质的医疗专业人员。

不会用来做什么

  • 不用于广告。
  • 不用于网站分析或用户追踪。
  • 不出售，不出租。
  • 不交给其他助手代理。
  • 不提交给其他付费健康服务。
  • 不放进本公开仓库或这些公开页面。

谁会处理数据

现在这些页面不处理健康数据。以后若你自己完成授权，预计会碰到这几方：

  • WHOOP：数据来源。你在 WHOOP 的授权页上同意或拒绝。WHOOP 如何保存它自己的数据，以其条款为准。
  • 你自己的 Grok Bot 服务：用来根据上述数据生成个人训练和恢复参考。该服务把数据保留多久、采用哪些安全措施，取决于你的配置和该服务当时的条款。本说明不能替它承诺具体的保留期限、删除时限或安全等级。
  • GitHub Pages：托管这些静态页面。它可能按自己的服务处理普通请求元数据，例如 IP 地址、用户代理、请求时间和路径。健康数据不应该出现在这些页面里。本说明不能保证 GitHub 的日志保留或删除时限。

除此之外，不打算把这些健康数据交给其他助手代理，或其他付费健康服务。

授权回调

回调页在本站的 /callback/。它只准备接收授权码流程的重定向结果：立刻从地址栏去掉查询参数和片段，不显示、不记录、不保存授权码和令牌，不自动跳转，也不把这些值再发出去。没有事先保存在本浏览器里的 8 位 state 时，它不会把返回的 state 标成已核对。令牌交换不在这个静态页面进行。

把静态页面登记为回调时，浏览器第一次打开它的 URL 可能含有授权码，GitHub Pages 可能因此在访问日志里看到该 URL。若你不能接受这一点，请使用你自己控制的机密客户端地址，而不要使用这个静态回调。细节写在回调页上。

你的选择

现在还没有连接可以断开，你可以随时离开这些页面。以后若你完成了授权，可以按 WHOOP 当时提供的方式撤销该应用的访问。撤销之后，助手不应再获取新的数据。已经进入你自己的 Grok Bot 服务的副本如何删除，要以该服务和你的配置为准，这里不作绝对承诺。

公开仓库

本仓库和 GitHub Pages 上的页面是公开的。不要把健康数据、授权码、访问令牌、刷新令牌、客户端密钥、密码或导出的 WHOOP 文件提交到仓库或这些页面。
